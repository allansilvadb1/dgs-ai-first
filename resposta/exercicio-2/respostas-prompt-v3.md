# Resposta para Pergunta 1:
Cargas classificadas como perigosas (classes 1 a 6 da ANTT) estão **expressamente excluídas** da política de devolução, não sendo permitido o retorno dessas mercadorias.

(Fonte: POL-001, Seção 3.2)

# Resposta para Pergunta 2:

O prazo de resolução para clientes Gold é de até **24 horas**.

(Fonte: Tabela SLA-2024)

# Resposta para Pergunta 3:

Para cargas acima de 500kg com destino a Manaus (Região Norte), aplica-se o multiplicador regional de **1.8** sobre o valor base do frete. O valor base não consta na documentação disponível.

Não encontrei o valor base na documentação. Recomendo escalar ao supervisor para obter o custo final.

(Fonte: PROC-042-v2, Seção 2)
