# Resposta para Pergunta 1:

Cargas classificadas como **perigosas (classes 1 a 6 da ANTT) não são elegíveis para devolução** — elas estão expressamente excluídas da política de devolução padrão.

*(Fonte: Política de Devolução POL-001, seção 3.2)*

---

> ⚠️ **Atenção:** Como não há prazo ou procedimento alternativo previsto na documentação disponível para esse tipo de carga, recomendo escalar para o supervisor caso o cliente solicite devolução nessa situação.

# Resposta para Pergunta 2:

Para clientes **Gold**, o SLA de resolução é de até **24 horas**, com resposta inicial em até **2 horas**.

*(Fonte: Tabela SLA-2024)*

# Resposta para Pergunta 3:

Para cargas acima de 500kg, o cálculo é: **valor base × multiplicador regional**. Como Manaus está na **Região Norte**, o multiplicador aplicável é **1.8**.

*(Fonte: PROC-042-v2, seção 2)*

---

> ⚠️ **Atenção:** O **valor base** não consta na documentação disponível. Não encontrei essa informação na documentação disponível. Recomendo escalar para o supervisor para obter o valor base e concluir o cálculo.
